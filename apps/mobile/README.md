# Мобильное приложение «AI-ассистент учителя»

Мобильная часть проекта: приложение для учителя начальных классов.

## Запуск

```bash
cd apps/mobile
npm install
npx expo start
```

Затем открой проект в приложении **Expo Go** на iPhone или Android-устройстве.

## Стек

- React Native
- Expo SDK 58
- expo-router
- TypeScript
- React Native Paper
- TanStack Query
- zustand
- react-hook-form + zod
